# HUMAN-RESORCE-MANAGEMENT-ANALYTICS
This project focuses on analyzing Human Resource data to derive meaningful insights related to employee performance, attrition, and overall workforce trends. The goal is to support data-driven decision-making in HR processes and improve organizational efficiency.
Analyze employee data to identify patterns in attrition and retention
Understand factors affecting employee performance and satisfaction
Evaluate workforce distribution across departments, roles, and demographics
Provide actionable insights for HR strategy and planning
The dataset contains employee-related information such as:
Demographics (age, gender, education)
Job details (department, role, salary, experience)
Performance metrics
Attendance and work patterns
Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
Attrition Analysis
Department-wise and Role-wise Insights
Salary vs Performance Analysis
Visualization of Key HR Metrics
